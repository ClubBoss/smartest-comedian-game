# Built-in buzzer audio sources

The game prefers short real-world recordings for selected built-in buzzer cues and keeps the procedural Web Audio pack as a runtime fallback if a remote recording cannot load.

New natural-cue sources added by the live-game polish wave:

| Built-in cue | Source | Author / provider | License | Playback treatment |
| --- | --- | --- | --- | --- |
| Whistle | Wikimedia Commons `File:WWS Policewhistle.ogg` | Work With Sounds / Konrad Gutkowski, Jonathan Nicolai, Anna Pietzuch | CC BY 4.0 | First ~1.2 s, volume adjusted |
| Clown horn | Wikimedia Commons `File:WWS Signalhorn.ogg` | Work With Sounds / Konrad Gutkowski, Jonathan Nicolai | CC BY 4.0 | First ~1.35 s, volume adjusted |
| Game-show buzzer | Wikimedia Commons `File:Buzzer.ogg` | BlastOButter42 | Public domain | Full ~1 s recording, volume adjusted |
