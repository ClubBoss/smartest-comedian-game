# Tournament Night V1 — Superseded

`STATUS = SUPERSEDED / NOT PRODUCT AUTHORITY`

The `league_8_v1` Tournament Night plan is no longer the Pilot 01 runtime model.

Current authority: [`THREE_GAME_PILOT_01.md`](./THREE_GAME_PILOT_01.md).

Pilot 01 is exactly three manually started, independent ordinary games with fresh scores:

1. Qualifier A
2. Qualifier B
3. Final

Do not use this superseded design to add or expose:

- tournament standings or stage UI;
- automatic advancement;
- cross-game score state;
- prize/money state;
- Double-or-Nothing wagering;
- automatic A -> B -> Final orchestration.

Previously merged tournament database/API code is legacy implementation only. It may remain dormant for reversibility until a separate migration audit proves destructive removal safe.

Historical details remain available in Git history prior to this supersession.
