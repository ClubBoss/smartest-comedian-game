# Pilot 01 — Human Blind-Test Evidence Sheet

Use with `PILOT_01_FINAL_HUMAN_TEST_CANDIDATE.md`.

## Recording rule

For each tester/card record the **first** stage at which the intended semantic answer was reached:

- `P` — prompt only
- `H1` — after Hint 1
- `H2` — after Hint 2
- `H3` — after Hint 3
- `N` — not solved after Hint 3

Also capture the first plausible wrong guesses. Do not count jokes that are obviously not genuine hypotheses.

## Reopen threshold

A card is **not** reopened for one subjective comment or one unusually knowledgeable tester.

Reopen only when evidence indicates a repeatable material problem, for example:

- multiple testers independently give the correct answer reflexively before the setup has landed;
- multiple testers cannot form a useful hypothesis even after H2;
- multiple testers simply repeat a hint as the answer because the hint already contains it;
- reasonable semantic answers produce inconsistent scoring;
- a factual/source challenge changes the premise;
- the same difficulty failure repeats across a cluster of adjacent cards.

## Post-test decision

For each card choose only one:

- `LOCK_PASS`
- `TARGETED_FIX`
- `SOURCE_RECHECK`

No new broad AI content wave is authorized from this sheet alone.
